# Plot Workbench 配色库设计草案

## 目标与范围

在「项目首页」「模板库」下方新增「配色表」入口。用户可以离线创建、编辑和保存有序配色方案，将方案中的单个颜色用于 Tavotto 的线条等图形元素，或将整组颜色作为热图色图。用户提供的截图作为卡片布局参考，整体沿用 Plot Workbench 现有风格。本次开发不升版、不创建标签、不发布或更新已安装的软件。

## 配色库和预置方案

- 配色方案属于当前选择的全局模板库目录，所有项目可使用；每个方案包括稳定 ID、名称、有序的六位十六进制颜色、创建及更新时间。文件仅存于本地，不上传或进入 Git；使用现有安全路径、锁和原子写入方式。切换模板库目录时切换到对应的配色库，不混入之前目录的数据。
- 配色表首页以色块卡片展示方案，支持按名称搜索、新建、打开编辑及删除；删除前确认。内置十几个初始方案，用于开箱体验和测试，包含分类、连续、发散配色。首次初始化按可重复且不会覆盖用户更改的方式写入，删除后不自动恢复。
- 用户提供的页面作为视觉和选色参考。网站本身内容可能由脚本加载，无法可靠读取时不声称已经取得其完整数据；初始科学配色可采用标明来源和许可证的 ColorBrewer 方案，例如 Set1、Set2、Set3、Paired、Accent、Dark2、Pastel1、Pastel2、Blues、Greens、Oranges、Purples、RdBu、BrBG、Spectral，最终数值在实现时对照原始数据核验并保留归属说明。
- 保存已有方案更新该方案；另存为需输入新名称并创建独立方案，不覆盖原方案。不同方案可以重名，通过 ID 区分。编辑未保存时离开需确认；保存失败保留当前编辑内容并提示原因。

## 配色编辑工作台

- 顶部是方案名称、保存、另存为及返回。工作区并列提供颜色输入 / 色轮、已加入的有序色块、图片取色区域；窄窗口纵向排列。
- 输入支持 `#RRGGBB`，也接受 `#RGB` 并在确认时规范为大写六位代码；无效或未完成输入保持原文本、说明错误，不修改当前选中色块。色轮变化同步输入值。按钮「添加色块」总是在末尾追加；选中已有色块时同步色轮和输入框，「替换色块」只替换当前选中的一个色块，「删除色块」删除所选色块并明确更新选择状态。空方案可以编辑，但至少有一个有效颜色才可保存。
- 普通点击选择一个色块；通过明确的多选方式选择恰好两个相邻色块后启用「制作渐变色」。无须方案只包含两个色块。弹窗输入生成总色块数 N（包括首尾），范围 2–1024，默认值 100；按两端在列表中的原顺序对 sRGB 的 R、G、B 通道线性插值并四舍五入，保留两个端点的原色。生成结果原位替换所选相邻两块，其他色块及顺序不变。例如 A、B、C、D 中选择 B、C 并生成 100 色，结果为 A、100 色渐变、D。无效、非相邻或超限选择给出明确提示，不改变方案。
- 图像拖入或通过文件选择器载入后，在单独区域按比例显示，可滚动或缩放查看。点击取色笔后移动到图片时显示紧邻光标的像素放大镜及颜色，点击从原始解码像素取色并同步代码和色轮；不会自动添加或替换色块。取消或关闭图片只清除临时图像，不改已保存的方案。图片仅在本机内存处理，不上传、不写入方案。透明像素按白色背景合成后输出六位 RGB；大图设可解释的尺寸上限，超限提示而非悄悄改变取样像素。

## Tavotto 使用与热图重放

- 在图内颜色选择器提供「配色表」入口，显示当前配色库中已保存方案；选择某个方案后可点击其任意色块，将颜色作为当前属性值提交，沿用既有撤销、渲染、事务和保存流程。不会一次性更改其他线条。
- 热图及支持颜色映射的图元，在原有色图选择器旁提供已保存配色方案；选中整套后可选择连续渐变或按色块分段，并明确应用到当前色图。保留原有色图、脚本原样恢复、多选、色条和共享色阶的绑定行为。
- 当前引擎的 `cmap` 可写值是已注册色图名称，不能只把未注册的名字发给 matplotlib。实现需设计受限、版本化、可验证的颜色序列值，并通过 Python 引擎、Rust supervisor、前后端协议和脚本导出 / 重放链一致处理；颜色数据以快照写入图形编辑记录，不依赖配色库之后仍存在或名称不变。不得绕过现有 session 认证、worker 隔离和 prepare → verify → commit 写回验证。旧项目及已有名称型色图保持兼容。
- 如果某图元不具备颜色映射能力，不展示可误用的整套色图操作。预览、保存和重开后的热图与色条须一致；验证失败则不提交。

## 验证

1. 配色增删改、保存、另存为、重启 / 切换目录、名称重复、无效代码和写入失败；确认用户颜色和图片不会进入 Git。
2. 梯度 2、3、100 和上限颜色的端点、顺序与精确结果；非相邻选择、相同颜色、非法数量和其他色块保持不变。
3. 在已知像素颜色的测试图中验证图片拖入、缩放、边缘和透明像素取色，放大镜位置与取色坐标一致；关闭图片不改已保存方案。
4. 真实 Matplotlib 线条、热图和色条的应用、撤销重做、保存、关闭重开、导出 / 脚本重放；修改或删除原配色后原图仍复现。覆盖多个热图共享色阶和原始脚本自定义色图恢复；包含前后端协议与 Python/Rust 同源测试、认证测试及实际浏览器交互。
5. 运行受影响的前后端定向测试、完整类型构建与必要的图形端到端检查，重建并核对要求的 playground / MCP 产物。每项新增核心不变式测试先反证能捕捉错误。
