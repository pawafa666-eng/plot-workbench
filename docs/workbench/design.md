# Plot Workbench 界面主题

2026-11-03 按用户提供的 `styles/duolingo-brand-package` 调整外观。采用亮绿主色、白色与浅灰表面、大圆角、带底部厚边的按钮和卡片；保留 Plot Workbench 品牌、现有页面、功能入口与操作流程。

## 唯一值来源与作用范围

工作台主题值在 `web/src/workbench/workbench-theme.css`。它在原有布局样式之后加载，只在包含 `data-workbench-app` 的文档生效，Radix 门户中的弹窗、设置和助手继承相同的语义 token。`workbench.css` 保留布局与组件结构，不另存主题色。

本次用户授权的工作台视觉要求覆盖继承的 Paper × Instrument 视觉参数；共享编辑器的行为、键盘契约、图标体系、文档模型、会话认证和写回事务不变式继续适用。上游 `index.css` 与 `DESIGN.md` 的默认主题保持各自同源，独立内嵌画布和 playground 不加载工作台主题。

## 颜色与字体

参考包的绿色 `#58CC02` 用于主按钮、品牌标记和装饰。按钮文字采用深绿；可读绿字与焦点环采用较深的语义色，避免亮绿配白字造成对比不足。状态色继续区分成功、警告与错误。

随应用打包 Nunito Latin 可变字体（约 39KB），以专用字体名 `Workbench UI` 加载，避免覆盖用户图表同名字体。来源为 Google Fonts 的 Nunito；SIL Open Font License 随构建复制到 `licenses/Nunito-OFL.txt`。中文依次回退到 Segoe UI、微软雅黑与苹方；运行时不请求在线字体。代码区保留等宽字体。图表 SVG、位图、图内文字、配色色块和导出内容不应用界面字体或滤镜。

## 密度与响应式

首页主操作高 40px，工作台普通按钮至少 32px；图内属性面板继续使用紧凑控件。导航有明确的浅绿底与边框选中状态。卡片保留标题、路径、数量及既有动作。

窄窗口允许标题与工具栏换行，模板分类改为横向排列，卡片改为单列；代码与预览在窄窗口上下排列。支持减少动态效果偏好，交互不依赖悬停与动画。

生成的浏览器截图和验收数据保留在忽略目录，不进入 Git。日常界面修改不升版、不构建发行安装包、不创建标签或 Release。
