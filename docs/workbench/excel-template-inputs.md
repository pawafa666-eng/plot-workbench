# Excel 模板输入与 Codex 浮窗

状态：按用户确认的方案实现；用户已决定发布，正在准备 1.3.6 发行及安装核验。属于第二批更新中的本次约定范围，不代表三批计划的第二批全部完成。

## 模板输入约定

- 创建模板使用一个 Python 文件和一个外部 Excel（`.xlsx` / `.xls`）。可以一次选择两个文件、分次选择或拖入；同一批超过两个文件、两个同类文件及其他格式都会拒绝。
- 文件区显示上传名称及 Python / Excel 类型标识，分别提供替换与删除。修改代码、更换或删除文件会使旧验证和尺寸确认失效。
- 先选择工作表和行列，确认有效数据；所选第一行可作为表头，表头不计入行数。原始 Excel 保持原样。
- 软件将最终选区生成为 `data.xlsx`，工作表名 `Data`，第一行是确认后的列名。运行目录内同时提供 `source.py`；代码使用相对路径或 `Path(__file__).with_name('data.xlsx')` 均可。已有 `data` DataFrame 也来自同一选区。
- 新运行使用隔离的输入目录，不覆盖项目目录里已有的 `data.xlsx`。正式模板版本目录同时保存 `source.py`、`data.xlsx`、JSON 数据快照和经过验证的预览。绘图记录冻结相同输入，图内编辑及冷重放沿用该快照。
- 模板使用时先导入自己的 Excel 选区，不再自动把模板示例数据填入新图。旧测试模板显示“尚未绑定 Excel”，可重新上传代码和 Excel 后运行、确认、保存。
- 数据面板提供“导出本次绘图数据”，导出最终选区对应的 Excel。表内以 `=` 开头的字符串仍作为文本保存，不变成新公式。

## 尺寸声明

运行成功后弹出尺寸确认，显示输入表的确定行列数。行、列分别支持 `+`（至少）、`−`（至多）、`±`（不限）和“无”（恰好）。数据不能为空；数量由用户声明，软件不推断任意 Python 的实际用数范围。

确认只改变行列要求，不修改已运行的代码、输入或图形。后端核对代码、数据及原规范是否仍对应同一次成功运行，再检查新要求是否容纳当前数据。未确认、输入不兼容、代码或数据已变化时拒绝保存。后续换数据仍需重新运行验证。

实际绘图值写死、只支持部分行数却声明不限等属于模板质量问题；不声称通过任意 Python 静态分析证明数据全部被使用。配色、线型、位置及计算常量允许保留。默认代码及助手提示不再提供内置绘图数据回退。

## Codex 助手

- 模板和图内编辑共用非模态浮窗：标题栏拖动，右下角调整大小，窗口变化时保持在可操作范围内；最小化继续保留会话，跨页面可重新展开。
- 服务确认接收消息后清空输入框，处理中锁定。提交失败保留输入；已接收但运行失败的消息保留在会话中，可重试。
- “设为默认模型”只影响 Plot Workbench。保存在应用数据目录的 `workbench-ui.json`，所有助手入口共用，不改 Codex 的全局配置；当前选择与默认相同则禁用。
- 右上角 `−` 最小化，`×` 结束对话。处理中结束须选择“强制结束”或“返回”。强制结束取消任务并丢弃未应用候选，迟到结果不能应用到原代码或图片。正式应用过程中保持原有防误关保护。
- 底部不再提供“关闭”“结束对话”按钮；修改仍经预览和显式应用，图内修改继续经过完整几何、像素与冷重放校验。
