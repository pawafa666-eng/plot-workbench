# 模板与配色分享

在模板库或配色表中点击「批量导出」，在列表中勾选多个项目后点击「导出 ZIP」。可以切换内容类型，在同一个包中同时放入模板和配色。搜索和切换类型不会清空已经勾选的项目。

接收方点击任一库中的「导入 ZIP」，将分享包拖入窗口，或点击「选择 ZIP 文件」。程序识别包内内容，保存后刷新两个库。配色始终保存在全局配色库；模板可选择全局模板库或当前项目模板库。分类会按名称对应，已有模板与配色不被覆盖，同名项目会自动加上「导入」后缀。

模板包含代码、示例数据、数据规范、说明、分类名称与一张 PNG 预览。分享包不复制工作台记录的项目标识、数据来源路径元信息、运行环境或图内编辑历史；代码与示例数据属于所选模板的内容。导入只解析和保存，不执行模板代码；导入模板以待验证草稿保存，预览仅供查看。首次保存编辑内容前，仍需通过现有的「运行并验证」流程。

格式由 `workbench/sharing.py` 定义：ZIP 根目录的 `library.json` 使用 `format=plot-workbench-library` 和 `version=1`，包含 `templates` 与 `palettes` 数组；PNG 预览位于 `previews/0000.png` 等独立条目。最多 500 项，包和展开后总量均不超过 64 MB，清单不超过 32 MB，单张预览不超过 4 MB。解析完整包并验证内容后才写入；不支持的版本、异常路径、重复条目、无效数据会被拒绝。写入发生错误时恢复原有库索引与配色记录。
