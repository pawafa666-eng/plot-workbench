本版补充代码导出包的使用说明：保留配套数据与环境文件；软件外运行时使用匹配的 Python、依赖和 Tavotto 引擎。

已安装 1.0.3 的用户可在「设置 → 关于与隐私 → 检查更新」中按「立即检查」，再确认下载并安装。应用启动时不会自动检查。更新包沿用相同的 minisign 签名密钥，安装前会验证签名。

首次安装请下载附件中以 `Setup.exe` 结尾的 Windows x64 安装包。安装包自带独立 Python，无需系统 Python 或终端。

工作台包含项目与子图、两级模板库、Excel／CSV 导入、代码绘图、Tavotto 编辑及 PNG／SVG／PDF 导出。项目与数据保存在本机，更新不迁移或上传用户数据。多图拼接画布暂不提供。
