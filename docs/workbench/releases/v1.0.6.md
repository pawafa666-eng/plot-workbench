本版补充工作台设置入口与更新使用说明。点击右上角齿轮「设置」，进入「关于与隐私 → 检查更新」，再按「立即检查」。原生菜单也可进入同一页面，启动和打开设置时不会自动联网检查。

1.0.5 用户可以从软件内下载并安装本版，安装前会验证同一 minisign 公钥对应的签名。首次使用请下载附件中以 `Setup.exe` 结尾的 Windows x64 安装包；安装包自带独立 Python，无需系统 Python 或终端。

工作台包含项目与子图、两级模板库、Excel／CSV 导入、代码绘图、Tavotto 编辑及 600 dpi PNG／SVG／PDF 导出。项目与数据保存在本机，更新不上传用户数据。多图拼接画布暂不提供。
