Plot Workbench 是 Windows 本地绘图工作台，基于 Tavotto v0.18.0，采用 AGPL-3.0-only 许可证。

## 下载与使用

下载附件中以 `Setup.exe` 结尾的 Windows x64 安装包并运行。安装包自带 Python 和绘图、Excel 依赖，日常使用无需终端或系统 Python。首次启动选择本地工作空间，再创建项目和子图。

## 功能

- 项目与子图管理，通用／项目模板库，分类、移动、收藏和回收站。
- Excel／CSV 导入，多段行列选择、表头、行列交换和转置。
- Python 代码绘图，600 dpi PNG、SVG 和 PDF 导出。
- 同一窗口内使用 Tavotto 编辑，保存前执行完整重放验证，支持重启后继续编辑及导出可执行代码包。
- 设置页手动检查更新。启动时不检查更新；用户确认下载后验证签名并安装。

本版修正 Windows 内置 Python DLL 隔离、冻结程序的表格处理，以及桌面启动验证对短暂握手文件的错误依赖。

项目、模板、表格和输出保存在本机工作空间，不会上传到 GitHub。多图拼接画布暂不提供。
