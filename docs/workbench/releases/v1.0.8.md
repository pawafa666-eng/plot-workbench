补充工作空间的备份、移动与切换说明。项目、模板、数据和图形输出保存在本机工作空间，不会随更新上传到 GitHub。多图拼接画布暂不提供。

已安装 1.0.7 的用户可点击右上角齿轮「设置」，进入「关于与隐私 → 检查更新」，按「立即检查」后确认下载并安装本版。安装前会验证签名；应用启动和打开设置时不会自动检查。

首次使用请下载附件中以 `Setup.exe` 结尾的 Windows x64 安装包。安装包自带独立 Python、绘图和 Excel 依赖，无需系统 Python 或终端。工作台包含项目与子图、两级模板库、Excel／CSV 导入、代码绘图、Tavotto 编辑，以及 600 dpi PNG、SVG、PDF 导出。
