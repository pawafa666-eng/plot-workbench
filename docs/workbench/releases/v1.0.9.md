Plot Workbench 是 Windows 本地科研绘图工作台，包含项目与子图、通用／项目模板库、分类与收藏、Excel／CSV 选区导入、代码绘图、Tavotto 编辑，以及 600 dpi PNG、SVG、PDF 导出。安装包自带独立 Python 和绘图依赖，无需系统 Python 或终端。多图拼接画布暂不提供。

右上角齿轮「设置」中提供手动更新：进入「关于与隐私 → 检查更新」，点击「立即检查」，再确认下载并安装。安装前会验证签名；启动和打开设置时不会自动检查。项目、模板和数据保存在本机工作空间，更新不会上传这些内容。

本版修正 Windows 安装验收中误关闭内部事件窗口的问题，安装、启动、渲染和正常关闭均通过实际安装包验证。首次使用请下载附件中以 `Setup.exe` 结尾的 Windows x64 安装包。
