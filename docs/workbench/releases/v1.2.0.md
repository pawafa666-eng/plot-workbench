# Plot Workbench 1.2.0

2026-10-28 修正版：按用户要求替换此前的同名发行包，版本号保持 1.2.0。已安装旧 1.2.0 的用户请手动覆盖安装本次附件。

- 在创建／编辑模板时加入 **Codex 助手**：输入要求、查看代码差异、确认应用，再运行验证并保存。
- 在 **Tavotto 图内编辑** 中加入相同的 Codex 入口：沿用当前数据与图内修改，先预览候选结果，通过完整重放、几何和像素校验后保存。多张图一并验证并更新。
- 复用本机 Codex CLI、登录状态及模型配置，支持查看进度、取消任务和打开编码 Agent 设置；旧任务不能覆盖更新后的代码或其他会话。
- 移除“在线模板”入口，保留本地 Python 模板导入、创建、分类与收藏。
- 调整发行流程：日常修改完成并验证后再决定发布；标签构建只准备并验证草稿，正式公开由维护者在用户决定后执行。
- 修复 Windows 更新器无法跟随系统代理访问 GitHub 的问题，检查更新和下载安装沿用同一个支持系统代理的客户端；连接失败时保留具体错误详情。

使用 Codex 前，请在 **设置 → 编码 Agent** 中确认本机 Codex 已安装、登录并启用。代码、修改要求和数据结构会交给所选 Codex 服务处理；表格数据值不会自动附加。生成结果需要确认应用，模板仍须运行验证，图内编辑仍须点击“完成并保存”。

Windows x64 用户请下载附件中的 `Plot-Workbench-1.2.0-Windows-x64-Setup.exe`。已有项目、模板和数据可继续使用；软件更新仍只在设置页由用户手动检查，安装前验证更新包签名。
