# Plot Workbench 1.2.1

- 创建模板和 Tavotto 图内编辑中的 Codex 助手改为居中、可放大的对话窗口，支持多轮交流、多行输入、停止和重试。
- Codex 可以先回答绘图问题，也可以接着上一轮草稿继续修改。代码差异可展开查看，只有确认应用后才会进入编辑器；保存前仍须完成既有验证。
- 修复 Windows 上较长对话可能超过命令行长度限制而无法启动的问题，并改进 Codex 错误提示。

软件沿用本机 Codex 的登录和模型配置。若提示当前模型不受所选 CLI 支持，请在设置中更新或选择兼容的 Codex 可执行文件。

已安装 1.2.0 的用户可以在 **设置 → 关于与更新 → 立即检查** 中发现 1.2.1，并自行决定是否下载和安装。
