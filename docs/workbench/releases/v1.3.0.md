# Plot Workbench 1.3.0

- 新增 **配色表**：内置 15 套科研配色，可创建、编辑、删除和另存自己的配色方案。
- 输入十六进制代码或使用色轮添加、替换色块；选择两个相邻色块，即可生成指定数量的渐变色。
- 支持从本机图片取色，取色时显示像素放大镜；图片不会上传。动态图片固定为取样时的一帧。
- Tavotto 图内颜色控件可以选用方案中的色块；热图和色条可应用整套配色，选择连续渐变或分段色块。保存图形时会保留颜色快照，之后修改配色方案不会改变已保存的图。

配色库保存在当前选择的全局模板库目录中，所有项目可使用。取色图片仅在本机内存处理。

在 **设置 → 关于与更新 → 立即检查** 中可发现新版，下载和安装由用户自行决定。
