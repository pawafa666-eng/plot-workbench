# Plot Workbench 1.3.1

- **界面更新**：采用亮绿主色、圆润字体、大圆角和带底部厚边的按钮与卡片，统一项目首页、模板库、配色表、编辑器、设置及对话框的视觉样式。
- **窄窗口适配**：工具栏可换行，模板分类和卡片布局随窗口宽度调整；较窄窗口下代码与预览上下排列。
- **离线字体**：界面字体随应用提供，运行时无需连接在线字体服务；图表字体、数据和配色不受界面主题影响。
- **修复自定义目录更新**：应用内更新沿用系统登记的现有安装目录，避免在默认位置另外安装一份。找不到有效旧安装、安装记录冲突或原目录中缺少程序时，安装器会停止并提示。
- **增加覆盖更新验证**：发布构建会先安装到含中文和空格的自定义目录，再执行更新，核对原位置的程序已替换、默认目录未新增副本，并确认安装登记和无关用户文件保持正确。

现有绘图、模板、配色和图内编辑操作流程保持不变。

在 **设置 → 关于与更新 → 立即检查** 中检查新版。若电脑上已有多份安装，请先核实正在使用的目录；本次升级不会自动清理其它安装副本。旧安装记录缺失或异常时，请使用本版本安装包重新安装。
